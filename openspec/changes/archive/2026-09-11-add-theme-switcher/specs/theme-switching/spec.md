## ADDED Requirements

### Requirement: 站点必须提供深色与浅色两套主题，深色为默认

系统 SHALL 提供且仅提供 `dark` 与 `light` 两个主题。在用户未表达过偏好时，站点 MUST 呈现深色主题。系统 MUST NOT 依据操作系统的 `prefers-color-scheme` 自动选择主题。

#### Scenario: 首次访问的用户看到深色主题
- **WHEN** 访客在没有任何本站 localStorage 记录的浏览器中打开任意页面
- **THEN** 页面以深色主题渲染
- **AND** 即使操作系统偏好为浅色，页面仍为深色

#### Scenario: 深色主题视觉与本次改动前完全一致
- **WHEN** 在深色主题下渲染任意页面
- **THEN** 所有元素的实际颜色值与本次改动前的构建产物逐项相同

### Requirement: 顶栏必须提供主题切换入口

顶栏右侧 SHALL 提供一个主题切换按钮，点击即在深色与浅色之间切换。该按钮 MUST 带有可访问名称，MUST 可由键盘聚焦并激活。

#### Scenario: 点击图标切换主题
- **WHEN** 用户在深色主题下点击顶栏右侧的主题切换按钮
- **THEN** 页面立即切换为浅色主题
- **AND** 再次点击切回深色主题

#### Scenario: 键盘可操作
- **WHEN** 用户用 Tab 键将焦点移到主题切换按钮并按下 Enter 或 Space
- **THEN** 主题发生切换
- **AND** 按钮呈现可见的焦点样式

#### Scenario: 按钮携带无障碍名称
- **WHEN** 屏幕阅读器读到该按钮
- **THEN** 能读出表明其用途及目标主题的名称

### Requirement: 主题偏好必须跨会话与跨页面持久化

用户选择的主题 SHALL 写入 localStorage，且使用独立于练习进度的存储键。刷新页面、站内跳转、以及重新打开浏览器后，站点 MUST 仍以该主题渲染。

#### Scenario: 刷新后保持
- **WHEN** 用户切换到浅色主题后刷新页面
- **THEN** 页面仍为浅色主题

#### Scenario: 站内跳转后保持
- **WHEN** 用户在浅色主题下从首页进入闯关页，再进入阅读页
- **THEN** 三个页面均为浅色主题

#### Scenario: 主题存储与进度存储互不干扰
- **WHEN** 用户切换主题
- **THEN** `lesson-progress` 存储项的内容不发生任何变化
- **AND** 清除主题存储项不会影响已保存的练习进度

### Requirement: 首屏渲染必须不出现主题闪烁

页面 MUST 在样式表生效之前确定并应用主题。任何情况下 MUST NOT 出现先渲染一种主题、再跳变为另一种主题的可见闪烁。

#### Scenario: 浅色用户刷新不闪深色
- **WHEN** 已选择浅色主题的用户刷新页面
- **THEN** 从首次绘制起页面即为浅色，全程无深色帧

#### Scenario: 主题判定不依赖 React 水合
- **WHEN** 检查构建产物的 HTML
- **THEN** 主题判定逻辑位于 `<head>` 内的同步内联脚本中
- **AND** 该逻辑不位于任何 React 组件内

### Requirement: 颜色必须由语义 token 驱动

所有主题相关颜色 SHALL 通过 CSS 变量形式的语义 token 定义，深色值定义在 `:root`、浅色值定义在 `[data-theme="light"]` 下。组件源码中 MUST NOT 出现硬编码的中性色色阶类名。

#### Scenario: 组件层无硬编码中性色
- **WHEN** 对 `src/**/*.tsx` 执行 `-(slate|gray)-\d+` 形式类名的检索
- **THEN** 匹配数为 0（改动前为 244）

#### Scenario: 新增主题只需改 CSS
- **WHEN** 需要调整任一主题的配色
- **THEN** 仅修改 `globals.css` 中的 token 值即可生效，无需改动任何组件文件

#### Scenario: 不随主题翻转的颜色单独成 token
- **WHEN** 在浅色主题下渲染品牌绿背景上的按钮文字
- **THEN** 文字仍为深色，未随中性色一同翻转为浅色

### Requirement: 浅色主题必须满足 WCAG AA 对比度

浅色主题下，正文文字与其背景的对比度 MUST 不低于 4.5:1；大号文字 MUST 不低于 3:1。

#### Scenario: 正文文字达标
- **WHEN** 测量浅色主题下正文、次级文字、链接与各自背景的对比度
- **THEN** 每一项均不低于 4.5:1

#### Scenario: 品牌绿文字在浅色下使用深阶
- **WHEN** 浅色主题下渲染绿色文字
- **THEN** 其色值对白色背景的对比度不低于 4.5:1
- **AND** 不直接沿用深色主题的 `emerald-300`（1.52:1）或 `emerald-400`（1.92:1）

### Requirement: 代码编辑器主题必须跟随站点主题

练习页的代码编辑器 SHALL 随站点主题切换配色，MUST NOT 固定为深色。

#### Scenario: 切换主题时编辑器跟随
- **WHEN** 用户在含代码编辑器的闯关页切换到浅色主题
- **THEN** 编辑器同步切换为浅色配色
- **AND** 编辑器中已输入的代码内容不丢失

### Requirement: 主题切换不得影响学习功能

主题切换 MUST NOT 改变练习进度、解锁状态、判分结果或 Pyodide 运行时状态。

#### Scenario: 切换主题不重置解锁进度
- **WHEN** 用户做对若干题解锁后续内容，随后切换主题
- **THEN** 已解锁的教学与练习仍然可见
- **AND** 已完成题目的完成标记保持不变

#### Scenario: 切换主题不重启 Python 运行时
- **WHEN** Pyodide 已加载完成后用户切换主题
- **THEN** Pyodide 不重新加载，判分立即可用
